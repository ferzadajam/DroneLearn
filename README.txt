DroneLearn — homepage design preview

1. Extract this ZIP.
2. Open the extracted DroneLearn_Design_Preview folder in VS Code.
3. In Terminal, cd to that folder.
4. If you already created a Python virtual environment elsewhere, you can activate it, or create a new one:
   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install Flask
5. Run: python app.py
6. Visit http://127.0.0.1:5000

This preview uses the school aerial video, school logo, and drone image you provided. No student photos are included. The navigation currently links to the features preview, not functional lessons/quizzes/dashboard. Keep original source images and video private until school permission for public use is confirmed.
